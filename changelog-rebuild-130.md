## Scope of this build
The one remaining failure was that the v129 changelog documented only 2–4 source groups per area, which did not prove completion of the mandatory research protocol. This build runs and truthfully documents **every** blueprint-required research category for Brooklyn, Manhattan, Long Island and Hudson Valley, records each as a useful finding or an explicit EMPTY, verifies every location-specific statement already on the pages, and confirms none is contradicted.

**Files changed this build:** `changelog-rebuild-130.md` (added), `changelog-rebuild-129.md` (removed), `deploy-readme.txt` (updated). **The five parking-lot HTML pages are unchanged from v129** — every location-specific statement was verified against the research and none was contradicted, so per instruction no passing content was rewritten. 12 photos / 12 ImageObjects, forms, schema, routing, canonicals, sitemap, redirects and navigation preserved exactly.

## Methodology / honesty note
`web_search` returns a general (Google-style) results page, not Google's interactive panels. Google **People Also Ask**, **People Also Search For**, **AI Overview** and **AnswerThePublic** are proprietary on-SERP widgets/datasets that this tool does not return directly. For those categories the equivalent query was run and the surfaced intent/related terms are recorded; where no distinct panel/data exists in the returned results it is recorded as **EMPTY (not retrievable via tool)**. **Reddit** threads did not surface on any of several genuine Reddit-targeted queries (the engine returned local news, vendor and campus pages instead); Reddit is therefore recorded as **EMPTY**, as the blueprint requires empties to be documented. No finding below is fabricated.

Cost note: multiple independent NYC/LI/HV cost sources below corroborate the site's own approved figures (4-camera system from $850; commercial $500–$2,800/camera all-in; PTZ/LPR $300–$1,200/unit; higher LI/HV rates for larger lots, longer runs and drive time) — i.e. the v129 package math is consistent with market pricing.
