## Distinct theses

**Wakefield** — the city line. The neighbourhood runs straight into the boundary, so identical houses built by the same developers sit in different municipalities and a contractor's coverage can stop mid-block. The page positions the NYS state licence as the thing that matters, tells readers to ask about credentials rather than coverage areas, and covers the pattern advantage of identically built runs of houses.

**Westchester Square** — solid masonry with no cavity. There is nowhere to fish a cable, so every run is surface-fixed, in a chase, or through an existing penetration. That inverts the usual arithmetic: the wiring becomes the expensive part and the equipment the cheap part, so keeping sound runs and replacing only the kit at each end is both cheaper and better. Includes a section on doing surface containment properly rather than apologetically.

**Williamsbridge** — systems carrying years of earlier repairs. Owner-occupied, long-held, hands-on households, so entry systems here have usually been worked on before. The page names the four things that recur (mis-rated transformer, mid-run join, mismatched part, wrong cable), states plainly that sound earlier work stays, and includes practical guidance on doing a homeowner repair that lasts.
