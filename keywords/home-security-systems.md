## Rules for these pages

- **Whole-home system angle.** These pages sell the complete home security system: alarm panel + door/window/motion/glass-break sensors + cameras + video doorbell + smart locks + phone app + central-station monitoring. Don't cannibalize the existing silos: the alarm-installation-* pages stay the money pages for "alarm installation"; security-camera-installation-* for "security camera installation"; home-automation-installation-* for "home automation"; smart-lock and doorbell-camera pages for those terms. Each home security page links once in context to its area's alarm, security camera, doorbell camera, smart lock and home automation pages where they exist, and the builder adds one contextual link back from those pages. Never change those pages' titles, H1s or URLs.
- **Burglar alarm phrases** in this list are used on these pages. Don't create separate burglar-alarm pages unless Anwar asks.
- **Monitoring and fees: say only what's true.** Central-station monitoring is through COPS. The tiers are $45/month (phone app, watch + control) and $30/month (keypad only). There is NO free self-monitoring plan to advertise. For "no monthly fee / no subscription / without monitoring / self monitored / unmonitored / subscription free" phrases, answer honestly in FAQs and comparisons (e.g. the customer owns the equipment outright; local siren-only or camera-app setups vs professional monitoring) and never claim Abstract Enterprises Security Systems offers a $0/month monitored plan. Contract terms (month-to-month, no contract) only if they're already stated on the site or Anwar confirms them.
- **No same-day promises.** "Same day home security installation" is a search phrase to answer, not a promise. Say we book fast and come out early in the day; never promise same-day installation.
- **Prices:** only prices Anwar has set that are already on the site. "Under $100 / $200 / $500 / $1000", "financing", "payment plans", "no upfront cost", "no credit check" and "free estimates" get used only if Anwar confirms the offer. Otherwise answer the question generally (what drives cost) and point to the price calculator / quote form.
- **Brands:** we install any alarm brand the customer wants; 2GIG is the house panel. Use brand phrases (ADT, Vivint, SimpliSafe, Ring, Honeywell/Resideo, Qolsys, DSC, Bosch, Abode, Arlo, Eufy, Lorex, Reolink, Nest, Wyze, Cove, Frontpoint, Brinks, Xfinity, UniFi, Ajax) for comparison tables, "local licensed installer vs national alarm company" content, and takeover/upgrade of existing panels (Honeywell Vista, DSC, Qolsys IQ). Never claim to be an authorized dealer for a brand we aren't partnered with (partners: Lorex, Luminys, Reolink; Uniview via wholesaler). Never knock a brand dishonestly.
- **Smoke / CO / flood sensors** appear only as alarm-panel add-on sensors for homes. No fire alarm system claims; no commercial fire alarm content on these pages.
- **Seasonal phrases** (Black Friday, Cyber Monday, holiday deals, clearance) only in a dated seasonal FAQ or tips section, never as a fake sale. A real promo needs Anwar's offer.
- **"Buy / shop / for sale / store / wholesale / kits / DIY kits"** phrases: link to the equipment store pages where they exist (see equipment-sales plan); otherwise frame as "buy the system installed." Never tell readers how to DIY-install (they're leads).
- Brand name always "Abstract Enterprises Security Systems", never "AESS". No Anwar byline. Real job photos only (alarm panels, keypads, sensors, doorbells from our jobs).
