## Distinct theses

**Norwood** — one building, two front doors, one system. The courtyard and H-plan six-storeys run two or three street entrances off a single basement board, which produces faults that exist nowhere else: cross-wired releases where the wrong door opens, a whole wing going quiet because the horizontal basement run between wings failed, and a transformer that only shows its shortfall when both doors are busy. Testing at one panel proves nothing.

**Olinville** — faults that come and go, and why. Buildings along the elevated line take sustained low-frequency vibration, which works terminations loose rather than breaking them. The result is intermittent faults where nothing is actually broken, and where a contractor who replaces components fixes nothing. The fix is usually labour-only: remaking connections properly.

**Park Versailles** — timber walls change the method. Wood frame construction gives stud cavities, so a run that would need surface containment in the surrounding brick stock can often be fished instead. The catch is that easy access invited decades of undocumented amendment, plus fire blocking and retrofitted insulation that compartment cavities invisibly.
